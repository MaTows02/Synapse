# Soutenir Synapse

Synapse est développé et maintenu par MaTows. Vous pouvez aider le projet de plusieurs façons :

- ajouter une étoile au [dépôt GitHub](https://github.com/MaTows02/Synapse) ;
- signaler un bug avec le [formulaire dédié](https://github.com/MaTows02/Synapse/issues/new/choose) ;
- proposer une amélioration ou un adaptateur matériel ;
- tester les nouvelles versions sur différentes configurations Windows ;
- contribuer au code ou à la documentation en suivant [CONTRIBUTING.md](CONTRIBUTING.md).

Les soutiens et partenaires affichés dans l’application sont gérés dans la fenêtre **Soutenir Synapse**.
