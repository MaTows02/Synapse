# Soutiens de Synapse

Le fichier `sponsors.json` alimente la page de soutien de **Synapse by MaTows**.

Chaque sponsor peut contenir les champs `id`, `name`, `tier`, `url`, `logo`, `since` et `example`. Les soutiens individuels utilisent uniquement `name` et `since`.

La copie distribuée avec l’application se trouve dans `src/Synapse.UI/Assets/Sponsors/sponsors.json`. Mettez les deux fichiers à jour avant une publication.
